Privacy Policy

Effective November 5, 2026

The short version

  • vixxing.com sets no cookies, runs no analytics or tracking scripts, and has no accounts, sign-ups, or contact forms.
  • The verification demo runs entirely in your browser. Codes you type into it are never sent anywhere.
  • Two third parties see basic request data when you load the page: GitHub, which hosts the site, and Google Fonts, which serves the typefaces.
  • The self-hosted Vixxing software does not send any data to us. If your employer runs it, your employer controls that data.

1. What this policy covers

This policy covers the website at vixxing.com (the “Site”), operated by the maintainer of the open-source Vixxing project (“we”, “us”). The Site is a static informational page about the software.

It does not cover:

  • Installations of the Vixxing software. Vixxing is self-hosted. Each organization that installs it runs it on its own servers and is solely responsible for the data it holds. See section 6.
  • GitHub. Links to the source code, documentation, and license go to github.com, which is governed by the GitHub General Privacy Statement.

2. Information we collect

We do not collect personal information through the Site. Specifically, the Site:

  • has no forms that submit data, no newsletter, no login, and no comment system;
  • sets no cookies;
  • does not use localStorage, sessionStorage, IndexedDB, or any other browser storage;
  • loads no analytics, advertising, social-media, or session-recording scripts; and
  • uses no tracking pixels or fingerprinting.

We have no server of our own behind the Site and receive no server logs from it.

3. What happens in your browser

The Site includes a small amount of JavaScript that runs locally on your device and sends nothing over the network:

  • Verification demo. The six-digit codes shown are generated in your browser from the current time. They are random demo values, not real TOTP codes, and are tied to no real account. When you type a code and press “Verify caller”, the check happens in your browser. The code is not transmitted, stored, or logged.
  • Copy button. Pressing “Copy” in the Quick Start section writes the shell commands to your clipboard. The Site writes to your clipboard only when you press that button and never reads from it.
  • Page effects. Scroll-based animations and the navigation bar's border use your scroll position locally. Nothing about your scrolling is recorded.

4. Third parties that receive request data

Loading any web page sends some technical information to the servers that deliver it. For the Site, that means:

GitHub Pages (hosting)

The Site is hosted on GitHub Pages. When you visit, GitHub receives standard request information such as your IP address, browser user agent, the page requested, and the time of the request. GitHub states that it may log visitors' IP addresses for security purposes. We do not have access to these logs. See the GitHub General Privacy Statement and the GitHub Pages data collection notice.

Google Fonts (typefaces)

The Site loads the Inter and JetBrains Mono typefaces from Google Fonts (fonts.googleapis.com and fonts.gstatic.com). Your browser therefore sends Google your IP address, user agent, and the referring page. Google states that the Fonts API does not set cookies and does not use this data to build advertising profiles. See the Google Fonts privacy FAQ and the Google Privacy Policy.

To avoid the Google Fonts request, you can block those domains with a content blocker. The Site falls back to your system fonts and works normally.

Links to other sites

Links to GitHub, Microsoft, Google, or other websites take you to services we do not control. Their own privacy policies apply once you leave the Site.

5. How we use and share information

We do not collect personal information through the Site, so we do not use, sell, rent, or share any. We do not use the Site for advertising or profiling.

If you contact us voluntarily, for example by opening a GitHub issue or emailing the maintainer, we use what you send only to respond. Anything you post on GitHub is public and is governed by GitHub's terms.

6. The Vixxing software you install

Vixxing is open-source software that organizations download and run on their own infrastructure. We are not a service provider for those installations:

  • The software contains no telemetry, analytics, or “phone home” behavior. It sends no data to us or to this Site.
  • An installation stores the data its operator enters: employee names, email addresses, usernames, enrollment status, and TOTP secrets. It stores these in the operator's own database. The software does not encrypt TOTP secrets at rest; protecting the database and host is the operator's job.
  • Enrollment emails are sent through the email provider the operator configures, such as Microsoft Graph or the operator's own SMTP server. That provider's terms apply.

If you are an employee whose authenticator was enrolled through Vixxing, the organization running it (usually your employer) controls your data. Direct any questions or requests about it to that organization. We cannot see, access, correct, or delete it.

7. Your choices and rights

Depending on where you live, you may have rights to access, correct, delete, or object to the processing of your personal information, for example under the GDPR or CCPA. Because the Site does not collect personal information, we have nothing about you to provide or delete. For data that GitHub or Google receives when you load the Site, use the controls those companies provide in the policies linked above.

8. Children

The Site is aimed at IT professionals and is not directed to children. We do not knowingly collect information from anyone, including children under 13 (or under 16 in the EEA).

9. Security

The Site is served over HTTPS by GitHub Pages. It is static and handles no user data, so there is very little to protect. For security issues in the Vixxing software itself, please open an issue or use GitHub's private vulnerability reporting on the repository.

10. Changes to this policy

If the Site's behavior changes, for example if we add analytics or a contact form, we will update this policy before or when the change takes effect and revise the date above. The full history of this page is public in the repository's commit log.

11. Contact

For questions about this policy, open an issue at github.com/miles-howell/vixxing/issues.
