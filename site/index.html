Questions about Vixxing

The rest is in the README on GitHub.

What does Vixxing cost?

Nothing. It is open source under GPL-3.0 and you host it.

Do I need Microsoft 365?

No. Graph is the default mailer; SMTP works on its own.

Where are the TOTP secrets stored?

In its database, unencrypted. CSV exports never include them.

Can I put it on the internet?

Not as shipped. Add TLS, secure cookies and access controls first.

Which authenticator apps work?

Any RFC 6238 app, such as Microsoft or Google Authenticator.

Who can use the dashboard?

Django staff users only. There is no self-service portal.
